2. Digital Records

nBooks maintains digital records as required by MTD for VAT. Records are stored digitally in a PostgreSQL database, with all data linked digitally from source (invoices, transactions) through to the VAT return submitted to HMRC — satisfying MTD's digital link requirement, with no manual re-entry or cut-and-paste between systems.

3. Fraud Prevention

We submit required fraud prevention headers with all MTD API calls, including device identifiers and browser metadata collected from the user's browser.
